# 自媒体选题库与评分工具

## 1. 项目名称

自媒体选题库与评分工具

## 2. 项目简介

这是一个面向单人创作者的 Web 应用，用于管理选题、配置评分模板、完成选题评分并进行复盘沉淀。  
第一版聚焦本地可用性与迭代效率，数据存储在浏览器 `localStorage`，不依赖后端数据库和登录系统。

## 3. 核心功能

- 选题库管理：新建、编辑、删除选题，支持搜索、分级展示、详情查看。
- 标签管理：独立管理标签（名称、颜色、描述），与选题状态分离。
- 评分模板管理：支持多模板、多评分标准、额外加分项，权重总和校验为 `1`。
- 选题评分：为具体选题选择模板并打分，自动计算总分并更新选题等级。
- 复盘管理：支持绑定选题复盘与独立复盘文档，手动填写发布数据与复盘结论。
- 个人设置：昵称、头像链接、主题色配置，支持刷新后持久化。

## 4. 技术栈

- Next.js（App Router）
- TypeScript
- Tailwind CSS
- shadcn/ui
- localStorage（前端本地数据存储）

## 5. 本地运行方式

```bash
npm install
npm run dev
```

浏览器访问：`http://localhost:3000`

质量检查：

```bash
npm run lint
npm run build
```

## 6. 当前版本功能

当前版本为 MVP（前端本地版），已包含：

- 底部导航 4 个页面：选题库、评分、复盘、我的。
- 选题的完整基础信息录入与编辑能力（标题、多级标题、标签、状态、链接等）。
- 评分模板创建与编辑，评分标准权重总和必须为 `1`。
- 针对具体选题评分并自动更新选题分级（S/A/B/C，已完成单独分组）。
- 复盘文档创建与编辑（支持绑定选题或独立文档）。
- 用户基础设置与主题色全局生效。

## 7. 后续计划

后续在不破坏现有结构的前提下，逐步扩展：

- 接入数据库与登录体系（多账号/多端同步）。
- 平台数据导入能力（保持手动录入兼容）。
- 竞品分析与 Agent 能力。
- 桌宠与互动组件（作为全局浮动组件，不新增独立底部导航）。
- 社群能力（仅在高频需求成立时考虑加入底部导航，且总项数不超过 5）。

## 9. 注意事项

- 第一版仅使用 `localStorage`，清理浏览器缓存会导致本地数据丢失。
- 当前版本不包含登录、后端接口、自动导入、AI 自动评分与竞品分析。
- 标签与状态严格分离：如“已完成”属于状态，不作为普通标签。
- 评分模板中评分标准权重总和必须为 `1`，否则不允许保存。
